# p = 10^27 + 103

The DANGER3 challenge's open frontier target, solved 2026-08-28 with this
repository's CUDA engine.

    p  = 1000000000000000000000000103
    A  = 792266506864025595923438866
    x0 = 484583117575631730716207764

This is an unconditional proof that p is prime. The point (x0 : 1) on the
Montgomery curve B*y^2 = x^3 + A*x^2 + x over Z/pZ has exact order 2^45:
45 doublings reach Z = 0 (mod p) and the 44th does not. Since
2^45 > q + 1 + 2*sqrt(q) with q = floor(sqrt(p)), no prime factor r <= sqrt(p)
can exist — such an r would give a point of order 2^45 on a curve over F_r,
exceeding the Hasse bound. Checking it costs 45 doublings.

## Verifying

Any of these is sufficient, and none trusts the search engine:

    # the official DANGER3 verifier (vendored here unmodified)
    python3 ../tools/vpp.py $(tail -1 triple.txt)

    # from first principles, no repository code at all
    python3 - <<'PY'
    from math import isqrt, gcd
    p  = 10**27 + 103
    A  = 792266506864025595923438866
    x0 = 484583117575631730716207764
    q = isqrt(p); k = (q + 1 + isqrt(4*q)).bit_length()
    C = (A + 2) * pow(4, -1, p) % p
    X, Z, prev = x0 % p, 1, None
    for _ in range(k):
        prev = (X, Z)
        U = (X + Z)**2 % p; V = (X - Z)**2 % p; W = (U - V) % p
        X, Z = U*V % p, W*(V + C*W) % p
    print("valid:", Z % p == 0 and gcd(prev[1] % p, p) == 1 and (1 << k) > q + 1 + 2*isqrt(q))
    PY

`pomerance_1e27_103.lean` is a machine-checkable Lean 4 / Mathlib proof of
the same statement, generated by DANGER3's `lean_vpp.py`.

## The run

| | |
|---|---|
| hardware | 16x RTX 5090 (3 RunPod pods: 8 + 4 + 4) |
| wall clock | ~52 minutes |
| curves tested, fleet | ~1.4 x 10^12 cover curves |
| curves on the winning GPU | 9.28 x 10^10, hit at 3097.9 s |
| aggregate rate | ~470 M cover-curves/s |
| compute cost | ~$9 |

The winning candidate came from GPU 0 of the 8-GPU pod. In record-stack
units the fleet had covered ~5.6 x 10^12 marks-equivalent, about 0.18*sqrt(p)
— roughly 1.8x the central expectation of 0.07-0.1*sqrt(p), which is
unremarkable given that solved leaderboard entries range from 0.014 to
1.68*sqrt(p). Search times here are near-exponentially distributed, so a
single run says little about the mean.

For scale: the previous frontier, 10^26 + 67, took 45 minutes on one RTX
6000 Ada. p = 10^27 + 103 is ~10x more work per unit of the same algorithm;
this run absorbed that with the 2.34x from the exact layers in `../cuda`
plus fleet parallelism.
